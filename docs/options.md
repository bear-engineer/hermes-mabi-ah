# 옵션 필터

`listings`, `trades`, `search`에서 쓰는 옵션 필터를 정리합니다. 경매장 API는 옵션으로 검색하지 못하므로 `mabi-ah`가 받아 온 매물을 거릅니다. 넓은 카테고리를 거르면 페이지마다 호출 1회가 들어가니 `--name`이나 좁은 `--category`를 같이 쓰세요.

플래그의 기준은 `mabi-ah describe`의 `filter_grammar`와 `option_families`입니다. 이 문서는 그 내용을 풀어 쓴 것입니다.

## 조합 규칙

- 플래그는 모두 반복할 수 있고, 여러 개를 주면 전부 만족하는 매물만 남습니다(AND).
- 하나의 `-o` 안에서 `|`로 값을 나열하면 OR, 맨 앞 `!`는 NOT입니다.
- 이름은 API를 부르기 전에 검사합니다.
  - 모르는 옵션 종류(`-o`의 `<종류>`): 종료 코드 2(`usage`). 메시지에 비슷한 이름이 붙습니다.
  - 모르는 인챈트 이름(`--enchant`), 모르는 세공 옵션 이름(`--reforge`): 종료 코드 3(`not_found`). `error.hint`에 `비슷한 이름: ...`이 나옵니다.
  - 아는 이름의 기준은 옵션 레지스트리, `data/facts`, 저장소·로컬 카탈로그, 라바뉴 참고 데이터입니다. 실제로 있는 이름인데 거절되면 `mabi-ah catalog learn --category <카테고리>`로 관측해 카탈로그에 넣으세요.
- 문법이 틀리면 종료 코드 2입니다.

## 옵션군별 플래그

### 인챈트 `--enchant`, `--enchant-rank`

```
--enchant '[접두|접미:]<이름>[(>=|<=|=)<랭크>]'
--enchant-rank '[접두|접미](>=|<=|=)<랭크>[,(>=|<=)<랭크>]'
```

- 슬롯은 `접두` 또는 `접미`입니다. 생략하면 어느 슬롯이든 됩니다.
- 이름은 정확히 일치해야 합니다(`날카로운`). 이름은 `mabi-ah catalog enchant --query <일부>`로 찾습니다.
- 랭크 순서: F < E < D < C < B < A < 9 < 8 < 7 < 6 < 5 < 4 < 3 < 2 < 1. `>=E`는 E~A와 9~1을 뜻하고, `>=F,<=A`처럼 쉼표로 범위를 줄 수 있습니다.
- 한 인챈트가 슬롯·이름·랭크를 한꺼번에 만족해야 맞습니다. `--enchant`와 `--enchant-rank`는 같은 해석기를 써서, `--enchant-rank '접미>=7'`처럼 슬롯을 앞에 붙일 수 있습니다.
- `인챈트`와 `인챈트 종류`(인챈트 스크롤 아이템) 옵션 모두에 적용됩니다.

### 세공 `--reforge`

```
--reforge '[<슬롯 1~3>:]<옵션명>[(>=|<=|=)<레벨>]'
```

- 슬롯을 안 주면 1~3번 중 어느 슬롯이든 됩니다. `2:최대 공격력>=18`은 2번 슬롯만 봅니다.
- 옵션명은 정확히 일치하거나 끝 단어들이 일치하면 맞습니다(`최대 대미지`는 `듀얼건 최대 대미지`와 맞음).
- 옵션명과 레벨 범위는 `mabi-ah catalog reforge --category <장비 유형>`, 이름 목록은 `mabi-ah catalog reference --kind reforge_option_names`로 봅니다. 라바뉴 이름은 띄어쓰기가 API와 다를 수 있습니다(`최대생명력`).
- `세공 랭크` 옵션은 아직 관측된 적이 없어 뜻을 모릅니다. 원문만 보존하고 필터 대상으로 해석하지 않습니다.

### 에르그 `--erg`

```
--erg '<등급 S|A|B>[(>=|<=|=)<레벨>]'
```

- 레벨은 현재 에르그 레벨(`option_value`)입니다. 최대 레벨은 `option_value2`에 따로 있습니다.

### 그 밖의 옵션 `-o`, `--option`

```
-o '[!]<종류>[:<하위>](>=|<=|=|~)<값>[|<값>...]'
```

- `<종류>`는 API의 `option_type`, `<하위>`는 `option_sub_type`입니다. 종류 이름은 `mabi-ah catalog option-types`로 봅니다.
- 연산자
  - `>=`, `<=`: 숫자 비교. 끝의 `%`는 무시합니다.
  - `=`: 값이 숫자면 숫자 비교, 아니면 글자 그대로 일치.
  - `~`: 포함 여부.
- `|`: 값만 나열하면 첫 조건의 종류·하위·연산자를 이어받습니다(`색상~빨강|파랑` = `색상~빨강` 또는 `색상~파랑`). 연산자를 넣으면 독립된 조건입니다(`에르그>=40|품질>=3`).
- `!`: 맨 앞에 붙이면 그룹 전체를 뒤집습니다(`!인챈트 불가능=true` = 인챈트 불가 옵션이 없는 매물).
- 개조·피어싱은 전용 플래그가 없어 `-o`로 거릅니다(예: `-o '특별 개조:R>=7'`, `-o '피어싱 레벨>=3'`).

### 도면류 제외 `--exclude-blueprints`

이름에 `도면`, `옷본`, `심볼`이 들어간 아이템을 뺍니다.

## 이스케이프

- `\|`: 글자 `|`, `\!`: 맨 앞의 글자 `!`, `\\`: 역슬래시.
- 이스케이프는 모든 `-o`에서 풀립니다. 역슬래시, 맨 앞 `!`, 이스케이프되지 않은 `|` 중 하나라도 있으면 OR/NOT 식으로 해석하고, 조건이 하나뿐인 식은 v0.1 필터와 같습니다.
- `watch add -o`는 단순 필터만 받습니다. `!`, `|`, 역슬래시가 있으면 종료 코드 2이고 `hint`가 `listings -o`를 안내합니다.
- 셸에서는 필터 전체를 작은따옴표로 감싸세요. `|`, `!`, `>`, `<`를 셸이 먼저 해석하지 않게 하려는 것입니다.

## 옵션군 (`describe`의 `option_families`)

| `option_type` | `option_sub_type` | `option_value` 형식 | `option_value2` 형식 | 관측 |
|---|---|---|---|---|
| 인챈트 | 접두\|접미 | `<이름> (랭크 <F..A\|9..1>)` | 없음; `option_desc`는 효과문을 쉼표로 이은 텍스트 | 관측됨 |
| 인챈트 종류 | 접두\|접미 | `<이름> (랭크 <F..A\|9..1>) (인챈트 스크롤 아이템)` | 없음 | 관측됨 |
| 인챈트 불가능 | 없음 | `true` | 없음 | 관측됨 |
| 세공 옵션 | 슬롯 번호 1~3 | `<옵션명> <N> 레벨` 또는 `<옵션명>(<N>레벨:<수치> 증가)` | 없음 | 관측됨 |
| 세공 랭크 | 미관측 | 미관측(의미 해석하지 않고 원문 보존) | 미관측 | 미관측 |
| 에르그 | 등급 S/A/B | 현재 레벨 정수 | 최대 레벨 정수 | 관측됨 |
| 특별 개조 | R\|S | 단계 정수 | 없음 | 관측됨 |
| 일반 개조 | 없음 | 사용 횟수 정수 | 최대 횟수 정수 | 관측됨 |
| 보석 개조 | 없음 | 정수 | 없음 | 관측됨 |
| 장인 개조 | 없음 | `<효과> <수치> 증가` 항목을 쉼표로 이은 텍스트 | 없음 | 관측됨 |
| 피어싱 레벨 | 없음 | 정수 | `+<N>` | 관측됨 |
| 에코스톤 각성 능력 | 없음 | `<효과> <N> 레벨 (<수치>)` | 없음 | 관측됨 |
| 토템 효과 | `<효과 이름>` | 레벨 정수 | 없음 | 관측됨 |

이 표는 `data/facts/option_families.json`에서 나옵니다. 위 표에 없는 종류도 API가 돌려주면 `catalog option-types`에 관측 값 수와 함께 나타납니다.

## 예시

```sh
# 접두 날카로운 인챈트가 붙은 장갑, 인챈트 랭크 E 이상
mabi-ah listings --category 장갑 --enchant '접두:날카로운' --enchant-rank '>=E'

# 어느 슬롯이든 최대 공격력 세공 18 이상, 도면류 제외
mabi-ah listings --category "한손 검" --reforge '최대 공격력>=18' --exclude-blueprints

# 2번 슬롯 최대 공격력 18 이상이고 에르그 S 40 이상
mabi-ah listings --category "한손 검" --reforge '2:최대 공격력>=18' --erg 'S>=40'

# 인챈트 불가가 아니고 색상에 빨강이나 파랑이 들어간 검
mabi-ah listings --category 검 -o '!인챈트 불가능=true' -o '색상~빨강|파랑'

# 최근 1시간 거래 중 인챈트 랭크 E 이상
mabi-ah trades --name "@롱 소드" --stats --enchant-rank '>=E'

# 토템 효과 값·레벨별 현재 최저가(최대 2페이지)
mabi-ah option-prices --category 토템 --family "토템 효과" --max-pages 2
```

`watch add -o`는 v0.1 문법(`<종류>[:<하위>](>=|<=|=|~)<값>`)만 받습니다. `!`, `|`, 옵션군 전용 플래그는 감시 규칙에 쓸 수 없습니다.
